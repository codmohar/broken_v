# Frontend

Plain HTML, CSS, and JavaScript frontend served by Vite.

## Run

```powershell
npm run dev -- --host 127.0.0.1 --port 5173
```

The frontend calls the FastAPI backend at `http://localhost:8000/api`.

## Active Views

- Overview
- Disease Detection
- Soil Analysis
- Weather Forecast
- Simulator

Removed from the UI: Dashboard, Analysis, Map, Overview Live Status, and Weather Zone Telemetry.
